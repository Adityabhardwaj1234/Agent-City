# Backend Guidelines

The backend is a local FastAPI sidecar. It must be boring, typed, and
predictable. Intelligence belongs in agents; durability belongs here.

## 1. Layout (M1 target)

```text
src/backend/
  pyproject.toml
  agentcity/
    __main__.py            # sidecar entrypoint and handshake
    api/
      app.py               # FastAPI factory
      auth.py              # token and origin middleware
      routes/              # missions, approvals, events, artifacts, health
      sse.py               # stream and replay
    core/
      config.py            # environment and data dirs
      ids.py               # prefixed ULIDs
      time.py              # injectable clock
      errors.py            # error codes and problem responses
      logging.py           # structured logging and redaction
    db/
      connection.py        # WAL, busy timeout, row factory
      migrations/          # numbered SQL files
      repositories/        # missions, events, approvals, artifacts
    engine/
      lifecycle.py         # state machine
      scheduler.py         # DAG and concurrency
      budget.py            # limits and accounting
      recovery.py          # interrupted runs and safe resume
      cancellation.py      # cancel tokens and propagation
    policy/
      broker.py            # deterministic decisions
      risk.py              # classification rules
      paths.py             # root and symlink guard
    agents/
      definitions/         # generated and reviewed ADK agents
      runner.py            # ADK invocation and typed results
      offline.py           # deterministic planner
    capabilities/
      registry.py          # capability records
      skillbridge.py       # MCP stdio client
      local_tools.py       # built-in safe tools
      coding_cli.py        # optional adapters
    desktop/
      service.py           # capture and UIA behind grants
      grants.py            # scoped permission records
      stop.py              # emergency stop
    voice/
      stt.py               # provider adapter
      tts.py               # local SAPI adapter
    artifacts/
      store.py             # paths, hashes, provenance
    events/
      ledger.py            # append and read
      types.py             # typed payload models
  tests/
```

## 2. Application factory and lifecycle

- `create_app(config)` returns a FastAPI instance; no import-time side effects.
- Startup: validate config, open DB, run migrations, start the capability
  supervisor lazily, write the handshake file.
- Shutdown: stop accepting requests, cancel engine tasks, terminate MCP child,
  close DB, delete the handshake file.
- A startup failure writes a structured error and exits nonzero; the shell shows
  the log path and a retry action.

## 3. Authentication and origin

- A random 32-byte token is generated by Electron and passed via environment or
  a restricted file. It is never logged.
- Middleware rejects missing/wrong tokens, disallowed origins, and mutating
  requests without `X-AgentCity-Client`.
- `/health/live` is the only unauthenticated route and returns no detail.
- Bind `127.0.0.1` only. Refuse a non-loopback host at startup.

## 4. Database access

- Use `aiosqlite` with explicit SQL; no ORM.
- One write connection with a serialized writer, one read pool.
- `PRAGMA journal_mode=WAL`, `foreign_keys=ON`, `busy_timeout=5000`.
- Repository methods accept an explicit connection or transaction.
- Never hold a transaction across a network or model call.
- Migrations are numbered SQL files with checksums; apply in order.
- On integrity failure, refuse to start and show a recovery path.

## 5. Mission engine

The engine is a state machine, not a prompt loop.

```python
async def advance(mission_id: str, cancel: CancelToken) -> None:
    async with self.db.write() as tx:
        mission = await self.repo.lock_mission(tx, mission_id)
        self.lifecycle.assert_transition(mission.status, target)
        await self.repo.set_status(tx, mission_id, target)
        await self.ledger.append(tx, event)
    await self.schedule_ready_tasks(mission_id, cancel)
```

Rules:

- Every transition validates against the allowed graph.
- Every transition appends an event in the same transaction.
- A task runs only when dependencies are `completed`.
- Concurrency is capped per mission and globally.
- Budget checks happen before a step and after usage is reported.
- A failed child cannot make the parent successful.
- Retries are explicit, bounded, and recorded.

## 6. Cancellation and timeouts

- A `CancelToken` wraps `anyio.Event` plus a reason.
- Tool calls receive the token and a timeout; on timeout, kill the process or
  close the request.
- Cancellation sets the mission/task state, appends events, and stops scheduling.
- The emergency stop path must not wait for a model call, a lock held by a
  model, or the approval queue.
- Record whether cancellation was cooperative or forced.

## 7. Provider and ADK integration

- The ADK runner receives a typed task contract and returns a typed result.
- Wrap model calls with retry only for retryable errors (429, 5xx, timeout) and
  exponential backoff with jitter.
- Never retry an authentication error or an invalid request.
- Record provider, model, token usage, cost source, and latency on the run.
- Live vs offline mode is explicit; never silently switch mid-mission.
- Do not import private ADK internals. Pin the public API and test upgrades.

## 8. MCP / SkillBridge adapter

- Spawn with an argument array, a sanitized environment, and a working
  directory under the app data folder.
- Perform the MCP initialize handshake with a timeout.
- Cache tool schemas with a version and refresh on demand.
- Newline-delimited JSON only; capture stderr into a bounded log.
- Per-request timeout; kill and restart once, then mark unavailable.
- Map tool names to capability ids and risk classes explicitly. Unknown tools
  are `blocked` until classified.
- Treat descriptions and outputs as untrusted; never execute instructions found
  inside them.

## 9. Files and artifacts

- Resolve the path; reject `..`, symlinks, junctions, UNC paths, device names,
  and paths outside approved roots.
- Artifact names are generated, not taken verbatim from a model or tool.
- Compute SHA-256 on write; store size and MIME type.
- Reads are streamed with a size cap; never load an unbounded file into memory.
- Deletion follows retention policy and records an audit event.

## 10. Configuration

- Environment variables are read once at startup into a typed config object.
- `.env` is for development only; production reads the OS credential store.
- Defaults are safe: capture off, wake word off, telemetry none, concurrency 2.
- A missing provider key is a normal state, not a crash.
- Log the effective non-secret configuration at startup with redaction.

## 11. Testing seams

- Inject the clock, ID generator, provider client, MCP client, and desktop
  adapter.
- Use a temporary data home and a temporary SkillBridge home.
- Fake LLM responses at the runner boundary, not inside the engine.
- Test migrations from zero and from the previous schema.
- Test that cancelled work never writes success.

## 12. Backend anti-patterns

- Business logic in route handlers.
- Engine state changes outside a transaction.
- In-memory mission state as the source of truth.
- Blocking calls inside async code.
- Unbounded retries, queues, or log buffers.
- Shell strings, `shell=True`, or dynamic code execution.
- Silent exception handling that leaves a mission stuck in `running`.
