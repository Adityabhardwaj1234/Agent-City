## Next milestone

Electron shell, FastAPI sidecar, SQLite event ledger, offline planner, approval gate, artifact, cancellation, and restart recovery wired end to end.

### Exit criteria

- App launches and reports sidecar health with no provider configured
- One mission creates a typed plan, requests approval, executes a deterministic local tool, and produces a verifier-approved artifact
- Events persist before the UI consumes them and survive an app restart
- Cancel stops an in-flight run and marks the mission cancelled
- Automated tests cover the happy path, approval rejection, cancellation, and restart recovery
- Evidence is recorded under docs/agentcity/evidence/
